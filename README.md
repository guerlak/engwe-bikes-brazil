# 🚴‍♂️ Engwe Bikes Brazil — E-commerce Experience

[![Next.js](https://img.shields.io/badge/Next.js-15-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind-4.1-38B2AC?style=for-the-badge&logo=tailwind-css)](https://tailwindcss.com/)
[![Framer Motion](https://img.shields.io/badge/Framer_Motion-12-FF0055?style=for-the-badge&logo=framer)](https://www.framer.com/motion/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.9-3178C6?style=for-the-badge&logo=typescript)](https://www.typescriptlang.org/)

Uma plataforma e-commerce de alto desempenho e design premium desenvolvida para a **Engwe Bikes Brasil**. Focada em proporcionar uma experiência de compra imersiva para bicicletas elétricas de última geração.

---

## ✨ Destaques do Projeto

- **⚡ Performance de Ponta**: Construído sobre o Next.js 15 para tempos de carregamento ultra-rápidos e SEO otimizado.
- **🖼️ Galeria Premium de Imagens**: Componente `ProductGallery` interativo com transições suaves via Framer Motion.
- **🌟 Prova Social Dinâmica**: Seção de depoimentos organizada em grid, exibindo avaliações reais de clientes verificados.
- **📱 Responsividade Total**: Interface fluida adaptada para desktops, tablets e dispositivos móveis.
- **🔗 Integração com Marketplace**: Botões estratégicos direcionando para checkouts oficiais no Mercado Livre e loja própria.
- **🎨 Design System**: Cores curadas (Zinc & Orange), tipografia moderna e micro-interações refinadas.

## 🛠️ Stack Tecnológica

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **UI & Estilização**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animações**: [Framer Motion](https://motion.dev/)
- **Lógica**: [React 19](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/)
- **Ícones**: [Lucide React](https://lucide.dev/)

## 🚀 Como Executar Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) (v18 ou superior)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)

### Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/engwe-bikes-brazil.git
   ```

2. Entre no diretório:
   ```bash
   cd engwe-bikes-brazil
   ```

3. Instale as dependências:
   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

Acesse [http://localhost:3000](http://localhost:3000) no seu navegador para ver o resultado.
